Requirements:
- The program must support one player against a computer opponent.
- The game must be random – each time you play the game a random number decides if
you or the computer go first.
- The game board using ASCII characters (e.g., -, +, and |) is the minimum requirement as
MARS does not support advanced graphics natively.
- You must indicate to the player if their space selected is incorrect
- You must indicate who won and congratulate them if they won and commiserate if they
lost
