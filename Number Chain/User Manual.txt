Number Chain User Manual:

What you need
- Java
- MARS 4.5
- Program files (all in one folder)

MARS settings

In the settings menu check that these are enabled:
- Assemble all files in directory
- Permit extended instructions
- Initialize program counter to global 'main' if defined

In the settings menu check that these are disabled:
- Delayed branching
- Popup dialog for input syscalls

Running the game
1. Start MARS
2. Open file main.asm
3. Check the settings above
4. Assemble (F3)
5. Start game with Go (F5)
6. Click inside the I/0 area and type answers to prompts
7. To play again, press Reset and then Go or assemble again

How To Play

You are player A and the computer is player B. As player A you start in the bottom-right corner with a chain of 1, 2, and 3 running up the diagonal. The computer starts in the top-left corner the same way. The starting player is randomly decided.

Rows are numbered 0 to 5 from the top and columns 0 to 5 from the left. On the board, 3A is a 3 that belongs to player A. 2B is a 2 that belongs to player B the computer. The '.' is an empty square that you can chain to.

On your turn you are asked for four numbers:
1. Source (Row) and Source (Column): the position of one of your own numbers.
2. Destination (Row) and Destination (Column): an empty square touching that number, diagonals included.

A new number, one higher than the one you chained from, is placed on the destination and belongs to you. 
If the move is not allowed (not your number, off the board, square already taken, or not touching), the game prints Invalid move and asks again from the source.
After your move the computer takes its turn and the board is shown again. If a player has no legal move, that turn is skipped automatically.

Winning

The game ends when neither player can move. The final board is shown, then the winner is printed: whoever reached the highest number. "Player 1 (A) WINS!" means you won, "Player 2 (B) WINS!" means the computer won, and equal highest numbers print "It's a draw!".
